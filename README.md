# Some of the programs I've written to make my life easier

- Graphite: an open-source, Flourish-style graph generator supporting histograms, graphs, and results visualization (complete with percentile and 1Q/median/3Q calculations built in). Uploada CSV or try any of the sample Excel files! Available at zhengjia.dev/graphite
- Autosolver: a self-contained HTML file to tackle those pesky Multiple Choice Questions (MCQs), with a Google Docs style UI and on-device semantic search. Upload any question bank (in JSON format) and search away.
